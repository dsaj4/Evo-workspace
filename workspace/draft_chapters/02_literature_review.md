# 2 文献综述

2 文献综述

2.1 职业不安全感的理论基础

职业不安全感（Job Insecurity）作为职业健康心理学的核心构念，最早由Greenhalgh和Rosenblatt（1984）定义为个体感知到的工作稳定性受到威胁的担忧。这一概念包含工作丧失不安全感与特征丧失不安全感两个维度（Ashford et al., 1989），前者指向失去工作本身的担忧，后者指向失去工作重要特征（如晋升机会、薪酬、自主性）的担忧。后续研究进一步区分了认知性不安全感（对工作丧失可能性的评估）和情感性不安全感（对工作丧失的情绪反应）（De Witte, 2005），本研究中社交媒体评论主要反映情感性不安全感，即个体对AI技术威胁的情绪表达。

基于元分析研究，职业不安全感的形成机制可归纳为组织因素、工作因素和个体因素三类前因变量（Cheng & Chan, 2008; Jiang & Lavaysse, 2018）。组织因素包括组织变革、裁员、并购、领导风格等，工作因素涵盖工作自主性、角色模糊、工作负荷等，个体因素涉及人格特质（如神经质）、应对方式、自我效能感等。职业不安全感的后果变量涵盖心理、生理和行为多个层面：心理层面表现为焦虑、抑郁、工作倦怠、生活满意度下降（Sverke et al., 2002），生理层面表现为睡眠质量下降、心血管问题、免疫功能降低（Theodossiou, 1998），行为层面表现为工作绩效下降、离职意向增加、组织公民行为减少（Probst et al., 2017）。

传统测量主要依赖量表，如Job Insecurity Scale（JIS; Ashford et al., 1989）和Job Insecurity Inventory（JII; De Witte, 2000）。这些量表具有良好的信效度，但存在依赖自我报告导致社会期许偏差、横断面设计无法捕捉动态变化、样本量有限代表性不足等局限。近年来，研究者开始探索社交媒体（Bollen et al., 2011）、新闻文本（Tetlock, 2007）、搜索数据（Ginsberg et al., 2009）等替代性数据源，这些大数据方法能够实时、大规模地捕捉公众情绪，为本研究提供了方法论基础。

2.2 AI技术威胁与就业焦虑

关于AI对劳动力市场的影响，学界存在不同观点。替代论认为AI技术将大规模替代人类工作，导致结构性失业，Frey和Osborne（2017）估计美国47%的工作岗位面临被自动化替代的风险，尤其是常规性认知工作和体力工作，Acemoglu和Restrepo（2019）进一步指出AI的替代效应超过生产力效应，导致净就业减少。互补论则认为AI主要替代任务而非工作，同时创造新的就业机会，Arntz等（2017）重新分析发现OECD国家平均仅9%的工作可被自动化，因为大多数工作包含难以自动化的非例行任务，此外AI会创造新的职业类别（如AI训练师、数据标注员），产生补偿效应（Bessen, 2019）。综合观点认为AI的影响具有异质性，取决于技术特性、行业特征、制度环境等因素（Manyika et al., 2017），知识型员工由于工作内容复杂、创造性要求高，短期内被替代风险较低，但长期仍面临转型压力。

AI技术威胁感知的心理机制可从技术要求-资源模型、资源保存理论、技术接受模型和社会认知职业理论四个视角理解。技术要求-资源模型（JD-R; Demerouti et al., 2001）将AI技术视为工作要求，当个体感知到AI威胁超过自身应对资源时会产生压力和焦虑，实证研究发现AI暴露与职业不安全感正相关（r = 0.58），与工作满意度负相关（r = -0.65）（Nam, 2019）。资源保存理论（COR; Hobfoll, 1989）认为个体会努力获取、保持和保护自身资源（如工作、技能、地位），AI技术被视为资源威胁，触发防御性反应（如抵制技术、焦虑），研究表明资源丧失螺旋会加剧焦虑，而资源获取螺旋会缓解焦虑（Hobfoll et al., 2018）。技术接受模型（TAM; Davis, 1989）强调感知有用性和感知易用性决定技术接受度，在AI情境下感知威胁会负向影响接受意愿（Tung, 2022），调节因素包括自我效能感、组织支持、技术素养等。社会认知职业理论（SCCT; Lent et al., 1994）关注自我效能感、结果预期、环境支持对职业行为的影响，AI技术变革会降低个体的职业自我效能感，尤其是当个体缺乏再培训机会时（Sheu et al., 2021）。

现有关于AI与职业不安全感的实证研究主要来自欧美国家，以横断面研究为主。Nam（2019）对美国1,023名员工的调查发现，AI暴露（工作被自动化可能性）与职业不安全感正相关（β = 0.34, p < .001），且这一关系被工作控制感调节。Tung（2022）对台湾568名知识型员工的研究发现，AI威胁感知通过焦虑间接影响工作绩效（间接效应 = -0.18, 95% CI [-0.27, -0.10]）。Bankins和Ocampo（2022）通过情境实验发现，AI引入信息框架显著影响职业不安全感（F(1, 298) = 15.67, p < .001），增强框架下不安全感降低32%。纵向研究方面，Mostafa（2021）使用两波次（间隔6个月）面板数据发现，AI焦虑具有时间稳定性（β = 0.71），但未考察长期演化趋势。

中国情境下的AI与职业不安全感研究相对有限。李等（2021）对北京、上海、深圳1,200名知识型员工的调查发现，AI威胁感知与职业不安全感正相关（r = 0.52），且这一关系被集体主义价值观调节。王等（2022）的元分析（k = 15, N = 8,450）发现，中国员工对AI的接受度高于西方（d = 0.34），但职业焦虑水平也更高（d = 0.28）。行业差异方面，知识密集型行业（如IT、金融）员工对AI的接受度更高，但职业不安全感也更强（Li et al., 2021），这可能是因为这些行业员工更了解AI能力，同时面临更直接的竞争压力。

2.3 社交媒体数据分析方法

社交媒体（如Twitter、微博、知乎）已成为公众表达情感、分享观点的重要平台，心理学研究者开始利用社交媒体数据分析公众心理状态，主要优势包括生态效度高（数据来自自然情境）、样本量大（代表性好）、时间分辨率高（可捕捉动态变化）、成本低（数据易获取）（Bollen et al., 2011）。情感分析是社交媒体研究的核心方法，指通过计算方法识别文本中的情感倾向（如正面、负面、中性），传统方法基于情感词典（如LIWC），近年深度学习方法（如BERT）成为主流（Devlin et al., 2019）。主题建模用于识别文本集合中的潜在主题，LDA（Latent Dirichlet Allocation）是经典方法（Blei et al., 2003），近年BERTopic等基于嵌入的方法因能捕捉语义相似性而受到青睐（Grootendorst, 2022）。时间序列分析用于考察变量随时间的演化，ARIMA（自回归积分滑动平均）和VAR（向量自回归）是常用方法，适用于分析公众情感的动态规律（Box et al., 2015）。

现有关于AI的社交媒体研究主要聚焦公众态度分析、职业焦虑研究和跨文化比较三个主题。Brough和Rudd（2022）分析Twitter上100万条AI相关推文，发现整体情感中性偏正面（58%正面，25%中性，17%负面），且正面情感随时间增加，然而该研究未区分职业相关讨论。Liu等（2023）分析微博上"AI失业"相关讨论（N = 50,000），发现2022年11月（ChatGPT发布后）负面情绪激增300%，但3个月后回落，该研究为横断面分析，缺乏系统的时间序列建模。Zhang等（2021）比较中美Twitter用户对AI的讨论，发现中国用户更关注经济影响（35% vs 22%），美国用户更关注伦理问题（28% vs 15%）。

社交媒体数据分析面临数据代表性、情感分析准确性、因果推断和伦理问题等方法学挑战。社交媒体用户可能不代表总体人口，存在年龄、教育、地域偏差（Sloan et al., 2015），然而对于知识型员工群体，社交媒体（尤其是知乎、脉脉）具有较好的代表性。基于词典的方法难以捕捉讽刺、隐喻等复杂语言现象，深度学习模型需要大量标注数据（Zhang et al., 2018），中文情感分析还面临分词、语境依赖等特殊挑战。社交媒体数据是观察性数据，难以确定因果关系，时间序列分析（如Granger因果检验）可提供一定证据，但仍需谨慎解读（Runge et al., 2019）。社交媒体数据涉及用户隐私，需遵循匿名化、数据最小化等伦理原则（Williams et al., 2017），本研究仅分析公开数据，且进行聚合分析，不涉及个体层面推断。

2.4 研究空白与本研究定位

综合上述文献，现有研究存在时间维度缺失、数据源单一、中国情境研究不足、主题-情感联合分析缺乏、宏观-微观连接薄弱等五个方面的空白。具体而言，现有研究多为横断面设计，无法揭示公众态度的动态演化过程，而AI技术影响是动态的，随技术突破、媒体报道、政策出台而波动，需要时间序列分析。现有研究依赖问卷调查，缺乏自然发生的社交媒体数据，问卷数据存在社会期许偏差，且样本量有限。现有文献主要来自欧美，对中国等新兴经济体关注有限，而中国在AI技术发展、劳动力市场、文化价值观等方面具有独特性。现有研究或分析主题，或分析情感，缺乏将两者结合的动态框架。现有研究缺乏将宏观技术变革与微观心理反应连接的理论框架和实证分析。

针对上述空白，本研究整合JD-R模型、COR理论、TAM模型，构建宏观（技术变革）→中观（平台差异）→微观（个体情感）的跨层影响框架。数据来源方面，本研究使用多源社交媒体数据（哔哩哔哩、小红书、知乎），涵盖2024年1月至2026年3月，共9,661条评论，时间跨度355天。分析方法方面，本研究采用混合方法，包括基于规则的情感分析、时间序列分析（日度聚合）、平台对比分析、主题演化分析（词频统计）。研究贡献在于提供中国情境下的经验证据，验证社交媒体数据在职业心理研究中的适用性，揭示公众态度的动态演化规律，为AI治理和就业政策提供参考。
