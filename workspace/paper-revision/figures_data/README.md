## 📊 各图表绘制指南

### Figure 1: 时间序列图

**数据文件**: `fig1_timeseries.csv`

**列**:
- `date`: 日期
- `insecurity_rate`: 日度表达率 (%)
- `rate_ma7`: 7 天移动平均 (%)

**Excel 绘图步骤**:
1. 选择三列数据
2. 插入 → 折线图
3. 添加事件标注（手动添加垂直线）
4. 设置 X 轴为日期格式
5. 添加图例和标题

---

### Figure 2: 森林图

**数据文件**: `fig2_forest.csv`

**列**:
- `event_id`: 事件编号
- `event_type`: 事件类型
- `irr`: 发生率比
- `ci_low`: 95% CI 下限
- `ci_high`: 95% CI 上限

**Excel 绘图步骤**:
1. 选择 irr、ci_low、ci_high 列
2. 插入 → 散点图
3. 添加误差线（自定义：+ci_high-irr, -irr+ci_low）
4. 添加垂直线 x=1
5. 按 irr 排序

---

### Figure 3: 动态衰减曲线

**数据文件**: `fig3_decay.csv`

**列**:
- `day`: 事件后天数 (0-14)
- `mean_effect`: 平均效应 (%)
- `std_effect`: 标准差
- `fitted`: 指数拟合值

**Excel 绘图步骤**:
1. 选择 day 和 mean_effect 列
2. 插入 → 带误差线的散点图
3. 添加 fitted 列作为折线
4. 添加水平线 y=0 和 y=5
5. 标注半衰期

---

### Figure 4: 箱线图

**数据文件**: `fig4_boxplot.csv`

**列**:
- `platform`: 平台 (zhihu/bili/xhs/all)
- `insecurity_rate`: 表达率 (%)

**Excel 绘图步骤**:
1. 按平台分组数据
2. 插入 → 箱线图（Excel 2016+）
3. 或使用插件：BoxPlotR
4. 添加均值点
5. 标注显著性

---

### Figure 5: 时间趋势图

**数据文件**: `fig5_trend.csv`

**列**:
- `date`: 日期
- `residual_rate`: 残差序列
- `loess`: LOESS 平滑值
- `trend`: 线性趋势值

**Excel 绘图步骤**:
1. 选择 date、residual_rate、loess、trend 列
2. 插入 → 折线图
3. 设置 residual_rate 透明度
4. 加粗 loess 和 trend 线
5. 添加趋势方程

---

### Figure 6: 安慰剂检验

**数据文件**: `fig6_placebo.csv`

**列**:
- `coef`: 安慰剂系数
- `bin`: 直方图分组（可选）

**Excel 绘图步骤**:
1. 选择 coef 列
2. 插入 → 直方图
3. 设置箱宽（建议 0.1）
4. 添加垂直线 x=0.1574（真实效应）
5. 添加文本框显示 p 值
