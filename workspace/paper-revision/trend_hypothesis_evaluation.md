# 评估报告：是否加入"时间上升趋势"假设

## 一、假设内容

**拟新增假设 H6**：

> **H6**：职业不安全感表达随时间推移呈上升趋势，表明 AI 技术影响的累积效应。

**统计方法**：时间序列趋势检验（线性/非线性趋势模型）

---

## 二、支持理由（✅ 加入的优势）

### 1. 理论贡献更强

| 维度 | 无趋势假设 | 有趋势假设 |
|:---|:---|:---|
| **理论深度** | 短期事件反应 | 长期累积效应 |
| **政策意义** | 事件后干预 | 持续性监测 + 干预 |
| **创新性** | 描述波动模式 | 揭示演化规律 |

如果有上升趋势，可以支持：
- **技术焦虑累积理论**：多次技术冲击产生累积心理影响
- **不确定性螺旋**：AI 发展越快，公众不确定性越高
- **适应失败假说**：公众无法完全适应快速技术变革

### 2. 与现有文献对话

**支持上升趋势的文献**：

| 研究 | 发现 | 来源 |
|:---|:---|:---|
| 技术变革加速导致适应性压力增加 | 焦虑水平随技术迭代上升 | Acemoglu & Restrepo (2019) |
| AI 媒体报道负面框架增加 | 公众风险感知上升 | 媒体效应研究 |
| 职业不安全感具有时间稳定性 | 两波次间隔 6 个月β=0.71 | Mostafa (2021) |

### 3. 方法上可行

```python
# 趋势检验模型
from statsmodels.tsa.stattools import adfuller, kpss

# 方法 1：ADF 检验（单位根检验）
# 如果拒绝单位根，说明存在确定性趋势
adf_result = adfuller(daily_data['insecurity_ratio'])

# 方法 2：KPSS 检验
# 如果拒绝平稳，说明存在趋势
kpss_result = kpss(daily_data['insecurity_ratio'], trend='c')

# 方法 3：线性趋势模型
import statsmodels.api as sm
X = sm.add_constant(np.arange(len(daily_data)))  # 时间变量
model = sm.OLS(daily_data['insecurity_ratio'], X)
results = model.fit()
# 时间系数显著 > 0 表示上升趋势
```

### 4. 政策意义更直接

如果存在上升趋势：
- **预警价值**：需要建立长期监测机制
- **干预时机**：越早干预越好（防止累积）
- **政策重点**：从事件应对转向系统性支持

## 三、风险与挑战（⚠️ 需要注意的问题）

### 1. 与初步发现矛盾

**您之前的分析显示**：
> "时间序列分析显示公众态度稳定，355 天内**未出现持续性焦虑积累**"

如果加入上升趋势假设，可能：
- 与数据不符（假设被证伪）
- 需要重新解释初步结果
- 增加论文内部一致性风险

**建议解决方案**：
- 将 H6 设为**探索性假设**（非核心假设）
- 或者修改为**条件性假设**（见下文）

### 2. 趋势可能非单调

AI 技术发展不是线性的，公众反应可能：
- **波浪式**：事件驱动波动，无明确趋势
- **U 型**：早期乐观→中期焦虑→晚期适应
- **阈值效应**：超过某临界点后快速上升

**建议**：
```python
# 检验非线性趋势
daily_data['time_squared'] = daily_data['time'] ** 2
model = sm.OLS(daily_data['insecurity_ratio'], 
               sm.add_constant(daily_data[['time', 'time_squared']]))
```

### 3. 混淆变量较多

可能影响趋势的混淆因素：

| 混淆变量 | 影响方向 | 控制方法 |
|:---|:---|:---|
| 季节性 | 求职季焦虑上升 | 加入月份虚拟变量 |
| 宏观经济 | 经济下行焦虑上升 | 加入经济指标 |
| 媒体曝光 | 报道量增加≠风险增加 | 加入媒体曝光度 |
| 平台用户构成变化 | 用户群体漂移 | 分平台分析 |

### 4. 因果表述风险

**问题**：时间趋势≠因果效应

```
❌ "AI 技术发展导致不安全感上升"
✅ "不安全感表达随时间呈上升趋势，与 AI 技术发展时间重合"
```

## 四、修改建议

### 方案 A：加入为探索性假设（推荐）

> **H6（探索性）**：职业不安全感表达可能随时间呈上升趋势，反映 AI 技术影响的累积效应。

**优点**：
- 不承诺一定成立
- 无论结果如何都可讨论
- 增加研究深度

**统计方法**：
```python
# 趋势检验
trend_model = sm.OLS(
    daily_data['insecurity_ratio'],
    sm.add_constant(daily_data['time_index'])
).fit()

# 解读：
# - 系数显著>0：支持 H6
# - 系数不显著：不支持 H6，但可讨论为什么
# - 系数显著<0：反向趋势，有趣发现
```

### 方案 B：修改为条件性假设

> **H6**：在控制重大事件影响后，职业不安全感表达仍随时间呈微弱上升趋势。

**优点**：
- 分离事件效应和趋势效应
- 更精确的理论预测
- 方法上更严谨

**统计模型**：
```python
# 包含事件虚拟变量和趋势变量
model = sm.OLS(
    daily_data['insecurity_ratio'],
    sm.add_constant(daily_data[[
        'time_index',           # 趋势
        'post_event_1',         # 事件 1
        'post_event_2',         # 事件 2
        # ... 其他事件
        'weekend',              # 控制变量
        'month'                 # 季节性
    ]])
).fit()

# 解读 time_index 系数
```

### 方案 C：分为两个竞争假设

> **H6a**：职业不安全感表达随时间呈上升趋势（累积效应假说）
> 
> **H6b**：职业不安全感表达随时间保持稳定（适应假说）

**优点**：
- 直接检验两个竞争理论
- 无论哪个成立都有贡献
- 避免"假设被证伪"的问题

## 五、与现有假设的关系

### 潜在冲突：H3 vs H6

| 假设 | 内容 | 时间尺度 |
|:---|:---|:---|
| **H3** | 事件后 14-21 天恢复基线 | 短期（事件后） |
| **H6** | 随时间呈上升趋势 | 长期（355 天） |

**表面冲突**：如果每次事件后都恢复基线，何来上升趋势？

**解决方案**：

```
图示：短期恢复 + 长期上升

不安全感
    ↑
    │      ╭───╮         ╭───╮
    │      │   │    ╭────┤   │
    │  ╭───┤   │    │    │   │    ╭────
    │  │   │   │ ╭──┴────┤   │ ╭──┴────
    │  │   │   │ │       │   │ │
────┴──┴───┴───┴─┴───────┴───┴─┴────────→ 时间
   E1      E2        E3    E4
   
   └───────┘ └───────────┘ └───────────┘
    短期恢复   短期恢复      短期恢复
       ↓         ↓           ↓
    基线 1    基线 2      基线 3
       └────────┴───────────┘
              长期上升
```

**解释**：
- **短期**：每次事件后恢复到"当时"的基线
- **长期**：基线本身随时间缓慢上升

**修改 H3 表述**：
> **H3**：职业不安全感表达在事件后 14-21 天内恢复到事件前基线水平。

**增加 H6 表述**：
> **H6**：在控制事件效应后，职业不安全感表达的基线水平随时间呈微弱上升趋势。

## 六、实证检验建议

### 6.1 预分析：查看数据趋势

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 绘制时间序列 + 趋势线
plt.figure(figsize=(14, 6))
sns.lineplot(data=daily_data, x='date', y='insecurity_ratio', label='日度数据', alpha=0.5)

# 添加 30 天移动平均
daily_data['ma30'] = daily_data['insecurity_ratio'].rolling(30).mean()
sns.lineplot(data=daily_data, x='date', y='ma30', label='30 天移动平均', linewidth=2)

# 添加线性趋势
from sklearn.linear_model import LinearRegression
X = np.arange(len(daily_data)).reshape(-1, 1)
y = daily_data['insecurity_ratio'].fillna(0)
model = LinearRegression().fit(X, y)
trend = model.predict(X)
sns.lineplot(x=daily_data['date'], y=trend, label='线性趋势', color='red', linestyle='--')

plt.xlabel('日期')
plt.ylabel('不安全感表达占比')
plt.title('职业不安全感表达的时间序列')
plt.legend()
plt.savefig('trend_visualization.png', dpi=300)
plt.show()

# 输出趋势系数
print(f"趋势斜率：{model.coef_[0]:.6f} /天")
print(f"355 天总变化：{model.coef_[0] * 355 * 100:.2f} 个百分点")
```

### 6.2 正式检验

```python
# 趋势显著性检验
import statsmodels.api as sm

X = sm.add_constant(np.arange(len(daily_data)))
y = daily_data['insecurity_ratio'].fillna(daily_data['insecurity_ratio'].mean())
model = sm.OLS(y, X).fit()

print(model.summary())

# 关键输出：
# - const: 初始基线
# - x1: 每日变化量（斜率）
# - P>|t|: 显著性
```

### 6.3 结果解读模板

| 结果 | 斜率 | P 值 | 解读 |
|:---|:---:|:---:|:---|
| 显著上升 | >0 | <.05 | 支持 H6，累积效应存在 |
| 不显著 | ≈0 | >.05 | 不支持 H6，适应假说成立 |
| 显著下降 | <0 | <.05 | 反向趋势，公众逐渐适应 |
