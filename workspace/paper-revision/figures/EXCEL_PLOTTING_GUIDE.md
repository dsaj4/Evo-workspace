## Figure 1: 时间序列图

### 数据文件
`fig1_timeseries.csv`

### 数据列
- A 列：`date` (日期)
- B 列：`insecurity_rate` (不安全感表达率)
- C 列：`rate_ma7` (7 天移动平均)

### 图表类型
**组合图**: 
- 日度数据：散点图或面积图（浅蓝色，透明度 70%）
- 7 天移动平均：折线图（深红色，线宽 2pt）

### 绘制步骤
1. 选择 A、B、C 三列数据
2. 插入 → 推荐的图表 → 组合图
3. 系列 1（日度数据）: 面积图，颜色 `#2E86AB`，透明度 70%
4. 系列 2（移动平均）: 折线图，颜色 `#A23B72`，线宽 2pt
5. 添加事件标注：插入 → 形状 → 垂直线（红色虚线）

### 格式设置
- **标题**: Figure 1 职业不安全感表达的时间序列（2024.10-2026.03）
- **X 轴**: 日期（格式：2024-10）
- **Y 轴**: 不安全感表达率 (%)
- **图例**: 右上角
- **网格线**: 水平网格线，透明度 70%

### 颜色方案
- 日度数据：`#2E86AB` (蓝色)
- 移动平均：`#A23B72` (紫红色)
- 事件标注：`#FF0000` (红色虚线)

## Figure 2: 森林图

### 数据文件
`fig2_forest.csv`

### 数据列
- A 列：`event_id` (事件编号)
- B 列：`event_type` (事件类型)
- C 列：`irr` (发生率比)
- D 列：`ci_low` (置信区间下限)
- E 列：`ci_high` (置信区间上限)

### 图表类型
**带误差线的散点图**

### 绘制步骤
1. 选择 A、C、D、E 列数据
2. 插入 → 散点图
3. 添加误差线：
   - 右键点击数据点 → 添加误差线
   - 自定义：负误差 = IRR - CI_low，正误差 = CI_high - IRR
4. 按事件类型着色：
   - tech_positive: `#2E86AB` (蓝色)
   - job_negative: `#A23B72` (紫红色)
   - policy: `#F18F01` (橙色)
   - report: `#C73E1D` (红色)

### 格式设置
- **标题**: Figure 2 各事件后职业不安全感表达效应的森林图
- **X 轴**: 发生率比 (IRR)
- **Y 轴**: 事件编号（从上到下排列）
- **参考线**: X=1 处添加红色虚线
- **误差线**: 95% CI，线宽 1pt

### 关键提示
- IRR > 1 表示事件后表达增加
- IRR < 1 表示事件后表达减少
- CI 不包含 1 表示统计显著

## Figure 3: 动态衰减曲线

### 数据文件
`fig3_decay.csv`

### 数据列
- A 列：`day` (事件后天数，0-14)
- B 列：`mean_effect` (平均效应)
- C 列：`std_effect` (标准差)
- D 列：`fitted` (指数拟合值)

### 图表类型
**带误差线的散点图 + 拟合曲线**

### 绘制步骤
1. 选择 A、B、C 列数据
2. 插入 → 散点图
3. 添加误差线：Y 误差 = std_effect
4. 添加拟合曲线：
   - 选择 A、D 列数据
   - 右键 → 添加数据系列
   - 图表类型：平滑折线图

### 格式设置
- **标题**: Figure 3 事件后职业不安全感表达的动态衰减曲线
- **X 轴**: 事件后天数
- **Y 轴**: 相对基线变化 (%)
- **参考线**: 
  - Y=0 处添加绿色虚线（基线）
  - Y=5 处添加灰色点线（+5% 阈值）
- **标注**: 添加文本框"半衰期 = 1.36 天"

### 颜色方案
- 观测值：蓝色散点 `#2E86AB`
- 拟合曲线：紫红色实线 `#A23B72`
- 基线：绿色虚线
- 阈值：灰色点线

## 常见问题

### Q1: 误差线显示不正确？
**A**: 检查误差值计算是否正确。Excel 要求输入绝对值，不是相对值。

### Q2: 箱线图须线太长？
**A**: 检查是否有异常值。Excel 箱线图默认显示 1.5×IQR 范围。

### Q3: 图表颜色打印后不清晰？
**A**: 使用高对比度颜色，避免相近颜色。添加图案填充（斜线、点等）。

### Q4: 中文显示为乱码？
**A**: 设置字体为"黑体"或"Microsoft YaHei"，避免使用系统默认字体。

### Q5: 图表文件太大？
**A**: 降低 DPI（150-300），或导出为 PDF 矢量图。
