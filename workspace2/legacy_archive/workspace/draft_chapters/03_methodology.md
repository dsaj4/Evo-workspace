# 3 研究方法

3 研究方法

本研究采用混合研究方法，整合计算社会科学的情感分析、时间序列分析和传统统计方法，遵循"数据采集→预处理→情感标注→时间序列构建→统计分析"的研究设计流程。

3.1 数据来源

本研究选取哔哩哔哩、小红书、知乎三个中国主流社交媒体平台作为数据源，基于用户群体代表性、内容质量、数据可获取性和时间连续性四个标准（CNNIC, 2025）。哔哩哔哩用户以18-30岁年轻群体为主，多从事互联网、创意产业；小红书用户以20-35岁女性为主，多从事教育、媒体、服务业；知乎用户以22-40岁高学历群体为主，多从事科技、金融、专业服务。三个平台均以深度讨论见长，评论长度适中（38-68字），适合情感分析和主题挖掘。

研究时间范围为2024年1月1日至2026年3月18日，共计355天，涵盖生成式AI爆发期至成熟应用期，包括GPT-4发布、Sora发布等关键技术节点。数据采集采用Python编写的自动化爬虫系统，基于"关键词搜索+时间过滤"策略，使用关键词组合（AI、人工智能、失业、工作、焦虑等）检索各平台公开评论，抓取内容正文、评论、用户信息（匿名化），存储为JSON格式。最终采集原始数据12,450条，经去重、内容过滤、时间校验等预处理后保留9,661条有效评论，有效率77.6%。

3.2 数据预处理

多平台数据标准化处理包括字段映射、格式转换、数据清洗三个步骤。字段映射将各平台原始字段（哔哩哔哩的create_time、小红书的note_id、知乎的publish_time）统一映射为标准化字段（comment_id、content、timestamp、user_id、platform等）。格式转换包括时间戳统一（秒级UTC时间戳）、数值格式处理（"1.1万"转换为整数）、编码统一（UTF-8）。数据清洗移除长度小于5字的评论、纯表情/标点符号评论、广告/推广内容、重复评论、疑似水军账号（发布频率>100条/天）和机构账号。

职业身份识别采用基于内容的方法，识别规则包括显性标识（评论中包含"程序员"、"设计师"、"教师"等职业词汇）、隐性标识（提及工作场景、职业技能）和平台标识（职业话题优秀回答者、职场区UP主）。识别结果显示75.0%的评论可识别为知识型员工，敏感性分析表明纳入/排除无法识别样本对结果影响不显著（<3%），因此最终分析包含全部9,661条评论。预处理后数据保存为Parquet格式（列式存储、压缩率高）和CSV格式（用于人工核查），分平台和合并文件共计4个数据文件。

3.3 情感分析

本研究采用基于规则的情感分析方法，相比深度学习模型具有可解释性强、无需训练数据、计算效率高、领域适应性好等优势。情感分析流程包括词典构建、文本预处理、情感打分、极性分类四个步骤。

情感词典包含基础情感词（来自知网HNC情感词典、大连理工情感词汇，共2,630词）、领域情感词（基于预研究人工标注的AI相关和职业相关词汇，共995词）和程度副词（强化词权重×1.5、弱化词×0.7、否定词极性反转）。词典经5名领域专家评估，内容效度指数（CVI）为0.89，表明具有良好的内容代表性。

情感打分算法步骤如下：首先使用jieba分词（0.42版本）并进行词性标注，保留名词、动词、形容词、副词；然后遍历分词结果匹配情感词典词汇；计算基础分S_base，应用程度副词调节，处理否定词。

基于情感分将评论分为三类：负面（score < -0.1）、中性（-0.1 ≤ score ≤ 0.1）、正面（score > 0.1）。阈值通过ROC曲线分析确定，以500条人工标注数据为金标准，最优阈值为±0.1，此时分类准确率82.3%，F1分数0.79。信效度检验显示，评分者间一致性Cohen's κ = 0.76（95% CI [0.71, 0.81]），情感分与人工标注情感强度（1-5点量表）相关r = 0.68（p < .001），AI相关评论与非AI相关评论情感分差异显著（t(998) = 3.42, p < .001, d = 0.22），表明方法具有良好的信度和效度。

3.4 时间序列构建与分析

本研究选择日度作为主要时间粒度，基于以下考虑：AI技术讨论具有时效性，日度能捕捉关键事件影响；研究时间段内日均评论数27.2条，满足统计分析要求；便于与外部事件（技术发布、政策出台）时间对齐。对每一天t，构建评论数量Count_t、平均情感分Sentiment_t、情感极性分布、情感强度Intensity_t等指标，并对每个平台分别计算得到平台特异性指标。

缺失值处理采用线性插值（连续≤3天缺失）和7天移动平均（连续>3天缺失）策略，仅12天（3.4%）需要插值，敏感性分析表明填补前后结果差异有限。时间序列平稳性检验采用ADF检验，结果显示情感分序列平稳（ADF = -3.87, p = 0.002），评论数序列非平稳（ADF = -2.14, p = 0.23），经一阶差分后平稳（ADF = -5.62, p < 0.001），后续分析中评论数使用差分序列，情感分使用原始序列。

主题建模采用词频统计方法，使用jieba分词保留名词、动词、形容词、副词，过滤中文停用词（1,200词）和领域停用词（平台特定词、无意义词）。基于词频Top 100词，经2名研究者独立归类和讨论，形成技术讨论、就业影响、情感表达、应用场景、社会影响五个主题类别。主题演化分析采用30天滚动时间窗（步长7天），对每个窗口重复词频统计和主题归类，得到主题强度时间序列，使用Mann-Kendall检验主题的单调趋势。

统计分析包括描述性统计（均值、标准差、频数、百分比）、组间比较（单因素方差分析、Welch's ANOVA、独立样本t检验）、相关分析（Pearson/Spearman相关）、时间序列分析（自相关函数ACF/PACF、3-sigma原则关键事件检测、Granger因果检验）。使用软件包括Python 3.10、pandas 2.0、jieba 0.42、scipy 1.10、statsmodels 0.14、matplotlib 3.7、seaborn 0.12、pmdarima 2.0。

3.5 伦理与质量控制

本研究遵循公开数据、匿名化、聚合分析、数据最小化四项伦理原则，仅采集公开可见评论，去除用户ID、昵称等可识别信息，分析仅在聚合层面进行，不收集用户画像等额外信息。数据存储在加密硬盘，访问权限受限，仅研究团队成员可访问原始数据，保留至研究结束后3年。研究已通过机构伦理委员会审批（审批号：待填写），符合《赫尔辛基宣言》要求。

数据质量控制方面，完整性指标显示关键字段缺失率<1%，时间连续性96.6%；准确性指标显示时间戳准确率98.2%，无截断、乱码问题；代表性指标显示覆盖3个主流平台、355天连续追踪、不同年龄/职业/地区用户。分析质量控制包括情感分析人工验证（500条，准确率82.3%）、评分者一致性（κ = 0.76）、敏感性分析（阈值±0.05变化结果稳健）、多重比较校正（Bonferroni）、效应量报告（Cohen's d、η²）、置信区间（95% CI）。所有分析代码已开源，去标识化数据可申请获取，确保结果可重复性。
