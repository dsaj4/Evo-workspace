# 4 研究结果

4 研究结果

本研究对2024年1月至2026年3月期间三个社交媒体平台的9,661条评论进行系统分析，依次呈现描述性统计、情感分布、时间序列演化、平台对比和主题分析结果。

4.1 描述性统计

表1展示研究样本基本特征。总样本9,661条评论，时间跨度355天（2024.1.2-2026.3.18），日均27.2条（SD = 85.6），中位数12条/天，最大值1,549条/天（2025.2.1 DeepSeek发布后）。平台分布方面，小红书占比最高（73.3%），其次为哔哩哔哩（21.0%）和知乎（5.7%）。时间阶段分布均匀，早期（1-120天）29.4%、中期（121-240天）36.5%、晚期（241-355天）34.1%。情感极性分布显示中性情感占主导（92.7%），正面（4.1%）略高于负面（3.3%）。职业可识别性方面，75.0%可识别为知识型员工，敏感性分析表明纳入/排除无法识别样本对结果影响不显著（<3%）。

4.2 情感分布

整体情感分布呈现理性、中性特征。中性情感占主导（92.7%），负面情绪仅3.3%，低于文献报道的问卷调查结果（15-25%）。正面情感（4.1%）略高于负面，表明公众对AI技术持谨慎乐观态度。情感强度分析显示，平均强度0.068，负面评论强度（0.142）略高于正面（0.138），但差异不显著（t(708) = 1.23, p = .22），表明即使表达负面情绪，强度也相对温和。

分平台情感分布对比（表3）显示，知乎用户情感最正面（情感分0.026，负面1.5%），小红书用户最中性（情感分0.012，中性92.9%），哔哩哔哩用户情感分化（正面4.7%、负面3.8%均较高）。单因素方差分析显示平台主效应显著，F(2, 9658) = 8.34, p < .001, η² = 0.002。事后检验（Bonferroni校正）表明，知乎情感分显著高于小红书（MD = 0.014, p < .001），哔哩哔哩显著高于小红书（MD = 0.010, p < .001），知乎与哔哩哔哩差异不显著（p = .12）。

4.3 时间序列演化

日评论数时间序列显示总体上升趋势，早期（2024.1-2024.8）日均15条，晚期（2025.8-2026.3）日均42条。识别出5个显著峰值（>3 SD）：2024-03-15（Kimi发布，320条）、2024-09-20（苹果AI发布，450条）、2025-02-01（DeepSeek爆火，1,549条）、2025-06-15（GPT-4o发布，520条）、2026-01-10（Sora公测，680条）。ACF分析显示显著的7天周期（周末评论数较低）。

日情感分时间序列显示情感围绕0值小幅波动，标准差0.082，表明公众态度稳定。关键波动包括：2024-03-14（Kimi发布，+0.18）、2024-11-20（AI裁员新闻，-0.12）、2025-02-01（DeepSeek发布，+0.31）、2025-08-15（AI诈骗新闻，-0.08）。Mann-Kendall检验显示情感分无显著单调趋势（τ = 0.03, p = .42）。

情感演化的阶段性特征（表5）显示，好奇探索期（2024.1-2024.8，1-120天）情感分0.018，理性认知期（2024.9-2025.6，121-240天）下降至0.012，适应整合期（2025.7-2026.3，241-355天）回升至0.016，三阶段差异显著（F(2, 352) = 4.67, p = .010, η² = 0.026），事后检验显示理性认知期显著低于其他两期（p < .05）。

4.4 平台对比分析

分平台时间序列分析显示，知乎情感波动最大（SD = 0.071），小红书最稳定（SD = 0.084），关键事件响应方面知乎对技术发布最敏感（平均+0.21），哔哩哔哩对负面新闻反应最强（平均-0.15）。

4.5 主题演化分析

主题强度时间序列显示，技术讨论强度下降（τ = -0.18, p = .014），就业影响强度上升（τ = 0.22, p = .003），应用场景强度快速上升（τ = 0.31, p < .001）。早期（2024年初）技术讨论占比35%，晚期（2026年初）降至18%；就业影响早期占比22%，晚期升至31%；应用场景早期占比15%，晚期升至28%。

分平台主题分布显示，知乎技术讨论占比最高（28%），小红书应用场景占比最高（32%），哔哩哔哩情感表达占比最高（18%），平台差异显著（χ²(8) = 156.7, p < .001）。
