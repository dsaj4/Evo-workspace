# 论文框架重大修改总结报告

## 修改背景

根据评审意见，原论文存在**重大框架缺陷**：
1. **概念混淆**：负面情绪 ≠ 职业不安全感，缺乏概念等价性论证
2. **因果缺失**：仅有描述性统计，无因果关系验证
3. **标题夸大**："影响"一词暗示因果关系，与研究设计不匹配

## 修改方案

采用**方案 A**：修改标题 + 弱化结论（不补充因果分析）

**新标题**：**AI 技术威胁的公众情感演化：基于多源社交媒体数据的动态分析**

**修改理由**：
- 与研究设计匹配（描述性 + 时间序列）
- 修改工作量可控（约 4 天）
- 仍具有方法创新和数据新颖性贡献

## 核心修改要点

### 1. 概念界定

**关键说明**：
> "本研究通过社交媒体情感分析捕捉的是公众对 AI 技术威胁的情感表达模式，而非直接测量职业不安全感构念本身。"

这一说明已添加到：
- 2.1 节末（concept_clarification.md）
- 摘要（00_abstract_revised.md）
- 讨论 5.1 节（05_discussion_revised.md）
- 结论 6.1 节（06_conclusion_revised.md）

### 2. 因果性表述替换

| 原表述 | 新表述 |
|:---|:---|
| X 对 Y 的影响 | X 与 Y 的关联 / X 背景下 Y 的反应模式 |
| 影响机制 | 关联模式 / 反应模式 |
| 导致/引起 | 伴随/相关 |
| 调节作用 | 关联差异 / 情境差异 |
| 效应/效果 | 模式/特征 |
| 验证了...影响 | 揭示了...关联模式 |

### 3. 理论贡献重新定位

**从**：验证因果关系、跨层影响机制
**到**：描述情感模式、提出分析框架、方法论创新

### 4. 局限性强化

新增五大局限：
1. 概念效度局限（情感≠构念）
2. 因果推断局限（观察性设计）
3. 样本代表性局限（平台用户偏差）
4. 情感分析方法局限（82.3% 准确率）
5. 时间跨度局限（355 天仍较短）
